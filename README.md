# ThoughtSpace — Blog Platform with Comments

A responsive mini blogging platform built with HTML, CSS, and vanilla JavaScript.

## Features
- Create and publish blog posts with author, title, and story content
- Comment on any post
- Show comment counts and latest stories
- Delete posts
- Save posts and comments in browser `localStorage`
- Responsive layout for desktop and mobile
- Basic HTML escaping for user-submitted text

## Run the project
1. Download and extract `blog-platform-with-comments.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to run it in your browser.
4. Alternatively, open the folder in VS Code and use the Live Server extension.

## Important note
This is a front-end demo. Data is saved in the current browser on the current device; it does not yet use a shared database or user authentication. For a production multi-user platform, add a backend and database.
